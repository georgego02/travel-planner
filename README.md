# Планировщик поездки

Мобильный сайт семейной поездки: маршрут по дням и на карте, учёт расходов, подготовка, сборы и идеи с голосованием.
Данные хранятся в Google Таблице, сайт размещается бесплатно на GitHub Pages и устанавливается на телефон как приложение.

```
Google Таблица  ⇄  сайт на GitHub Pages  ⇄  телефоны всей семьи
   (данные)          (просмотр)              (просмотр, расходы, отметки, идеи)
```

## Если что-то не работает

| Проблема | Решение |
|---|---|
| «Нет доступа к таблице» | Доступ «Все, у кого есть ссылка → Читатель» |
| «Семейный код не подошёл» | Сверьте код в настройках сайта с `FAMILY_CODE` в скрипте |
| Кнопок «Расход» и «Идея» нет | В `config.js` не указан `SCRIPT_URL` |
| Голос не ставится | Укажите своё имя в настройках сайта (шестерёнка) |
| Точки нет на карте | Заполните «Координаты» или «Адрес» у события |
| Файл календаря не открылся | На iPhone откройте сайт в Safari (не из ярлыка), нажмите ещё раз и выберите «Добавить все» |
| Расход добавлен, но не виден в таблице | Подождите несколько секунд; без связи он ждёт отправки (видно плашку вверху) |
| Изменения из таблицы не видны на сайте | Нажмите кнопку обновления или подождите 1–2 минуты |
| Демо | Добавьте к адресу `?demo=1` |
| Проверить режим «во время поездки» | Добавьте к адресу `?now=2026-12-19T13:00` |
