# Планировщик поездки

Мобильный сайт семейной поездки: маршрут по дням и на карте, учёт расходов, подготовка, сборы и идеи с голосованием.
Данные хранятся в Google Таблице, сайт размещается бесплатно на GitHub Pages и устанавливается на телефон как приложение.

```
Google Таблица  ⇄  сайт на GitHub Pages  ⇄  телефоны всей семьи
   (данные)          (просмотр)              (просмотр, расходы, отметки, идеи)
```

## Возможности

**Маршрут** — табличка-указатель по городам с текущим участком, блок «Сегодня» с ближайшим событием,
лента дней, таймлайн каждого дня, фильтры, переключатель «Список / Карта». Во время поездки прошедшие дни свёрнуты.
Карточка события: «Проложить маршрут», сайт, добавление в календарь, копирование адреса.

**Карта** — все точки маршрута с номером дня на метке, фильтр по дню. Координаты берутся из столбца
«Координаты»; если он пуст, сайт сам найдёт место по адресу.

**Календарь** — кнопка «Добавить в календарь» скачивает файл `.ics`: события со временем попадают в календарь
телефона с напоминанием за 30 минут (все события или без идей).

**Бюджет** — *Расходы*: потрачено всего и сегодня, в среднем за день, график по дням, по категориям, лента трат;
кнопка «Расход». *План*: плановые суммы из маршрута, на человека.

**Подготовка** — *Дела*: что купить и забронировать до какого числа, с отметками «просрочено» и «через N дней».
*Вещи*: чек-лист сборов.

**Идеи** — предложения и голосование: каждый отмечает понравившиеся, популярные поднимаются наверх.

**Без интернета** — сайт, шрифты и карта-подложка интерфейса работают офлайн; изменения без связи
сохраняются на телефоне и отправляются автоматически.

Оформление описано в `DESIGN.md`.

## Часть 1. Сайт (один раз, около 15 минут)

### 1. Доступ к таблице
Таблица уже создана в вашем Google Диске: **«Мюнхен, Зальцбург, Вена — декабрь 2026 (планировщик)»**.

1. Откройте таблицу → **«Настройки доступа»**.
2. «Общий доступ» → **«Все, у кого есть ссылка»**, роль **«Читатель»**. Без этого сайт не прочитает данные.
3. Тех, кто будет править таблицу напрямую, добавьте по email с ролью «Редактор» (для записи с телефона это не нужно).

> Таблицу сможет открыть любой, у кого есть ссылка. Не храните в ней номера документов,
> коды бронирований и домашние адреса.

### 2. Репозиторий на GitHub
1. [github.com](https://github.com) → **«+» → «New repository»** → название `travel-planner`, **Public** → **Create**.
2. **«uploading an existing file»** → перетащите всё содержимое архива:
   `index.html`, `config.js`, `sw.js`, `manifest.webmanifest`, папки `icons`, `fonts`, `vendor`, `README.md`
   (папки `apps-script`, `template`, файлы `DESIGN.md` и `.nojekyll` можно тоже загрузить — сайту они не мешают).
3. **Commit changes**.

### 3. GitHub Pages
**Settings → Pages** → Source: «Deploy from a branch», Branch: `main`, `/ (root)` → **Save**.
Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/travel-planner/`.

### 4. Установка на телефон
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** меню ⋮ → «Установить приложение».

На этом этапе сайт работает на просмотр. Чтобы с телефона можно было добавлять расходы, отмечать вещи
и добавлять идеи, выполните часть 2.

## Часть 2. Запись с телефона (один раз, около 10 минут)

Запись идёт через небольшой скрипт Google Apps Script, привязанный к вашей таблице.
Он бесплатный и работает от имени владельца таблицы, поэтому участникам не нужны аккаунты Google —
достаточно ввести на телефоне семейный код.

1. Откройте таблицу → **Расширения → Apps Script**.
2. Удалите всё в файле `Code.gs` и вставьте содержимое файла `apps-script/Code.gs` из архива. Нажмите «Сохранить».
3. Семейный код задан в строке `const FAMILY_CODE = "tirol-7422";` — при желании замените на свой.
4. **«Развернуть» → «Новое развертывание»** → значок шестерёнки → **«Веб-приложение»**.
   - «Выполнять как»: **Я**
   - «У кого есть доступ»: **Все**
   - **«Развернуть»** → «Предоставить доступ» → выберите свой аккаунт.
   Google покажет предупреждение о непроверенном приложении — это ваш собственный скрипт:
   «Дополнительные настройки» → «Перейти на страницу проекта» → «Разрешить».
5. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).
6. В репозитории откройте `config.js` → карандаш → вставьте URL в `SCRIPT_URL: "…"` → **Commit**.
7. На телефоне откройте сайт → шестерёнка → укажите имя и семейный код → «Проверить код» → «Сохранить».

Сообщите семейный код родственникам — каждый вводит его один раз на своём телефоне.

Если позже поменяете код скрипта: «Развернуть» → «Управление развертываниями» → карандаш →
версия «Новая» → «Развернуть». Адрес `/exec` останется прежним.

## Как заполнять таблицу

| Вкладка | Содержимое |
|---|---|
| Поездка | Название, начало и конец (`ДД.ММ.ГГГГ`), участники через запятую, валюта, бюджет (необязательно), заметка |
| Маршрут | Одна строка — одно событие |
| Подготовка | Дело, крайний срок «До», кто, «Готово» (Да/Нет), ссылка, заметка |
| Сборы | Вещь, категория, кто берёт, «Да»/«Нет» в столбце «Взято» |
| Идеи | Предложения участников; «Голоса» — имена проголосовавших (ставятся с телефона) |
| Расходы | Фактические траты; удобнее добавлять с телефона, столбец ID заполняется автоматически |
| Как заполнять | Памятка, сайт её не читает |

### Столбцы вкладки «Маршрут»

| Столбец | Пример | Примечание |
|---|---|---|
| День | `4` | Номер дня; по нему события группируются |
| Дата | `19.12.2026` | |
| Время | `09:00` | Можно не заполнять — событие останется на своём месте |
| Город | `Мюнхен → Зальцбург` | Стрелка — для переездов |
| Адрес | `Domplatz` | Необязательно; с адресом маршрут в картах точнее |
| Что | `Рождественская ярмарка` | Заголовок события |
| Тип | `Переезд` | Переезд, Жильё, Еда, Экскурсия, Отдых, Покупки, Другое |
| Подробности, Ссылка | | |
| Стоимость, Валюта | `12.80`, `EUR` | Плановые суммы для раздела «План» |
| Статус | `Забронировано` | Идея → Планируем → Забронировано → Оплачено |
| Ответственный | `Егор` | |
| Координаты | `48.2030, 16.3690` | Широта и долгота для карты; можно не заполнять |

Не переименовывайте вкладки и заголовки столбцов. Прошлые версии: **Файл → История версий**.

## Доработка

- Код сайта — `index.html`, настройки — `config.js` (включая список категорий расходов).
- Править можно прямо на GitHub: файл → карандаш → Commit. Сайт обновится через 1–2 минуты.
- После изменения `index.html` увеличьте версию в первой строке `sw.js` (`planner-v4` → `planner-v5`),
  чтобы установленные на телефонах копии обновились.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| «Нет доступа к таблице» | Доступ «Все, у кого есть ссылка → Читатель» |
| «Семейный код не подошёл» | Сверьте код в настройках сайта с `FAMILY_CODE` в скрипте |
| Кнопок «Расход» и «Идея» нет | В `config.js` не указан `SCRIPT_URL` |
| Голос не ставится | Укажите своё имя в настройках сайта (шестерёнка) |
| Точки нет на карте | Заполните «Координаты» или «Адрес» у события |
| Файл календаря не открылся | На iPhone откройте сайт в Safari (не из ярлыка), нажмите ещё раз и выберите «Добавить все» |
| Расход добавлен, но не виден в таблице | Подождите несколько секунд; без связи он ждёт отправки (видно плашку вверху) |
| Изменения из таблицы не видны на сайте | Нажмите кнопку обновления или подождите 1–2 минуты |
| Демо | Добавьте к адресу `?demo=1` |
| Проверить режим «во время поездки» | Добавьте к адресу `?now=2026-12-19T13:00` |
